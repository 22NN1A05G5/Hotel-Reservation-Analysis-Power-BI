#  Hotel Reservation Analysis using Power BI

##  Project Overview

The **Hotel Reservation Analysis** project focuses on analyzing hotel booking data to understand reservation trends, guest behavior, stay performance, and operational efficiency. An interactive Power BI dashboard was developed to transform raw hotel data into meaningful business insights and actionable recommendations.

##  Project Objectives

- Analyze hotel booking demand and reservation trends.
- Understand guest booking behavior and preferences.
- Evaluate stay performance and hotel operational efficiency.
- Monitor room and staff performance.
- Identify booking cancellations, no-shows, and stay-related issues.
- Provide actionable recommendations to improve hotel operations and decision-making.

##  Business Scenario

Hotels generate large volumes of reservation and operational data. Analyzing this data helps management understand booking patterns, guest preferences, room utilization, and operational challenges.

This project uses Power BI to visualize key performance indicators (KPIs), identify business problems, and provide data-driven recommendations to improve hotel performance and guest satisfaction.

##  Dataset Overview

The project uses multiple CSV files representing different aspects of hotel operations.

| Dataset | Description |
|---|---|
| Guests | Guest details and booking-related information |
| Hotels | Hotel information and attributes |
| Rooms | Room details and room-related information |
| Bookings | Reservation details and booking status |
| Stays | Guest stay information and stay performance |
| Staff | Hotel staff details |
| Date Table | Date dimension for time-based analysis |

##  Project Workflow

1. **Data Import:** Imported hotel reservation datasets from CSV files into Power BI.
2. **Data Cleaning:** Checked data types, data consistency, unique identifiers, and data quality.
3. **Data Transformation:** Prepared and organized datasets using Power Query.
4. **Data Modeling:** Created relationships between relevant tables and established a date table for time-based analysis.
5. **DAX Calculations:** Developed measures for KPIs and business performance analysis.
6. **Dashboard Development:** Built interactive reports using charts, cards, tables, and slicers.
7. **Business Analysis:** Interpreted dashboard results to identify problems, trends, and improvement opportunities.

## Key Performance Indicators (KPIs)

The dashboard focuses on relevant hotel reservation and operational metrics, including:

- Total Bookings
- Total Guests
- Total Stays
- Total Revenue, where supported by the dataset
- Average Stay Duration
- Cancellation Rate
- No-Show Rate
- Room and Staff Performance Metrics
- Average Stay Rating
- Cancelled Stays
- No-Show Stays


##  Key Areas of Analysis

- **Booking Analysis:** Understand reservation demand and booking trends.
- **Guest Analysis:** Identify guest booking behavior and preferences.
- **Stay Analysis:** Examine stay duration and stay performance.
- **Room Analysis:** Evaluate room-related performance and utilization indicators.
- **Staff Analysis:** Review available staff performance metrics.
- **Problem Analysis:** Identify cancellations, no-shows, and other booking or stay issues.
- **Executive Reporting:** Present key metrics in a consolidated summary.

##  Business Insights and Recommendations

The dashboard supports management in identifying opportunities such as:

- Monitoring booking trends to improve reservation planning.
- Understanding guest preferences to enhance the customer experience.
- Tracking cancellations and no-shows to improve booking management.
- Reviewing room performance to support better room allocation.
- Evaluating staff-related metrics to identify operational improvement opportunities.
- Using KPI trends to support data-driven business decisions.
